# Sistema-de-Gest-o-de-Reclusos
Segurança institucional, histórico disciplinar e fichas criminais  Sistema corporativo de alta segurança projetado para controle de estabelecimentos correcionais. O sistema substitui livros de registros manuais, unificando a biografia do recluso, celas ocupadas, audiências judiciais, visitas autorizadas e conduta interna.
